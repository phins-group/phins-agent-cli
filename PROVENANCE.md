# Source provenance

PHINs Agent combines inherited engine/terminal code with PHINs contributions.
[NOTICE](NOTICE) identifies source authors, contribution scope and licenses;
[THIRD_PARTY.md](THIRD_PARTY.md) indexes dependency and asset notices.
The edition has no dependency on a private PHINs checkout or backend.

The upstream license text was verified at revision
`ef3fd5900fd33289576ea7853afacb3c2b06bf33`. That identifies the license text, not
the original code-import revision; exact revision mapping remains incomplete.
The original copyright and license text are retained as referenced in NOTICE.

Five audio files and 33 themes were compared with upstream reference
`c1615b1db9c2e7a955f2be1024e84bb74c90cc6b`. Audio matches the upstream blobs;
32 themes match except for their schema URL, and the PHINs default is modified.
Their inherited MIT attribution is retained. PHINs owns the logo and authorized
its inclusion. Trademark permission remains separate.

The historical demo comes from MIT-licensed `vercel/ms`.
[UPSTREAM.json](examples/live/UPSTREAM.json) pins its source and hashes; original
Zeit copyright/license remain. The added Node oracle is distinct from the
historical Mocha tests. Seeded fixtures are authored sanity tasks, not upstream
bug discoveries. Model-generated patches retain review and attribution duties.

`configs/source-manifest.json` verifies file integrity, package closure and
independent dependency links. It is not copyright clearance, a signed attestation
or proof of independent authorship. See [the submission draft](docs/SUBMISSION.md)
for the development-period contribution.
